# 🧹 Masadaki Toz Tanesi Sayacı

> **Dikkat:** Bu yazılım, insanlığın tozla olan ebedi mücadelesinde devrim niteliğindedir. Ciddiye alınmayacak kadar ciddidir.

## Neden Bu Proje Var?

Masanızda göremediğiniz milyonlarca toz tanesi var. Her biri bir hikaye. Her biri bir potansiyel alerji. Her biri... eşit.

Bu proje, Planck sabiti hassasiyetinde toz sayımı yaparak:
- Ev temizlikteki belirsizliği ortadan kaldırır
- Tozların insan haklarını tanır (kaçanlar özgürdür)
- Bilimi eğlenceyle birleştirir (asıl amacı bu değil ama öyle oldu)

## Kurulum

```bash
git clone https://github.com/Tentivory/masadaki-toz-tanesi-sayaci.git
cd masadaki-toz-tanesi-sayaci
python toz_sayaci.py
```

Python 3 yeter. Bağımlılık yok. Ruh hali yeter.

## Özellikler

- ✅ Gerçek zamanlı toz sayımı (hayali)
- ✅ Kaçan tozlara özgürlük tanıma
- ✅ 42 iterasyon (evrenin cevabı)
- ✅ Aşırı bilimsel görünüm, sıfır bilimsel değer
- ✅ KeyboardInterrupt ile güvenli çıkış (tozlar intikam almasın diye)

## Bilimsel Arka Plan

Toz taneleri kuantum süperpozisyonundadır. Saydığınız anda çökerler. Bu yüzden sayım asla tam doğru olmaz. Ama biz yine de sayıyoruz. Çünkü saymak önemlidir.

Gizli değişken `ozgurluk_katsayisi` her zaman 1'dir. Neden? Çünkü hiçbir toz diğerinden daha toz değildir.
